# Go Rural India

Marketing site for Go Rural India Pvt Ltd, a full-service rural marketing and
advertising agency in Hyderabad.

Next.js 16 (App Router, Turbopack) · Tailwind CSS v4 · Framer Motion · Lenis.

## Running it

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # typecheck + lint + production build
```

## Environment variables

Copy `.env.example` to `.env.local` for local work, and set the same keys in
the Vercel project for production.

| Variable | What it does |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical origin. Drives canonical tags, `sitemap.xml`, `robots.txt` and link previews. Defaults to `https://www.goruralindia.in`. |
| `RESEND_API_KEY` | API key from [resend.com](https://resend.com). Required for the contact form to deliver. |
| `CONTACT_FROM_EMAIL` | Verified sender address, e.g. `website@goruralindia.in`. Required. |
| `CONTACT_TO_EMAIL` | Inbox that receives enquiries. Falls back to the address in `src/data/content.ts`. |

**The contact form does not deliver until `RESEND_API_KEY` and
`CONTACT_FROM_EMAIL` are both set.** Until then `/api/contact` returns 503 and
the form shows WhatsApp, phone and email fallbacks. That is deliberate: an
enquiry form that accepts a lead and throws it away is worse than one that is
visibly down.

## Where things live

| Path | Contents |
| --- | --- |
| `src/data/content.ts` | The whole site's content: company details, the 13 service categories, 117 campaigns, client list, stats. Editing copy almost always means editing this file. |
| `src/lib/site.ts` | Canonical URL, shared description, Schema.org organisation data. |
| `src/app/globals.css` | Brand tokens (`--color-brand-red` etc.), Tailwind theme aliases, the `.btn-shine` utility. There is no `tailwind.config.ts`; Tailwind v4 is configured here. |
| `src/components/` | Page sections. `ui/` holds the reusable primitives. |
| `src/app/icon.png`, `apple-icon.png`, `opengraph-image.png` | Generated by `npm run optimise-assets`. Next.js picks them up by filename. |

## Images

Campaign photos go in `public/images/work/` and are referenced from the
`image` field of a `CaseStudy` in `src/data/content.ts`. A study with
`placeholder: true` and no `image` renders the "Photo coming soon" card
instead.

After adding or replacing an image, run:

```bash
npm run optimise-assets
```

It resizes and re-encodes everything in `public/images/`, regenerates the
icons and the Open Graph card, and keeps untouched originals in
`assets/originals/`. It reads from those originals, so it is safe to run
repeatedly.

## Deploying

Vercel builds the **`master`** branch of the **`GoRuralV2`** repository.

```bash
git push v2 main:master
```
